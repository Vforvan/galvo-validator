# V2 深孔候选：Ø0.1 mm × 深1 mm，音圈 ±3.5 mm

本候选保留原 V2 的四镜中心、58×40×2 mm 等口径镜面、四片物镜、出光轴和381.08×310×345 mm外包络，重新优化 L1/L2 的四个球面及 L2 轴向位置。音圈机械硬限位为−3.5～+3.5 mm，总行程7 mm；焦点位移由光路计算，不能直接视作7 mm。

[三维模型与孔内通道](https://vforvan.github.io/galvo-validator/v2/deep-hole/) · [原 V2 对照](https://vforvan.github.io/galvo-validator/v2/) · [原生工程](5AXIS_deep_hole_v2.zos) · [处方](design.json)

## 多姿态光斑一致性：当前主判据

新增 [角度×Z一致性图表](https://vforvan.github.io/galvo-validator/v2/deep-hole/pose-consistency/) 与 [Zemax模型使用说明](pose_consistency/README.md)。主判据是上位机移动扫描时，不同AOI、方位、Z高度和填充位置上的焦点光斑是否一致；单次孔壁掠入射投影只作辅助。

原生工程分为工件XY焦平面和真正垂直主光线的焦平面，每个工程有99组对应配置。每个姿态重新逆解五轴，并将观察面移到目标焦点；没有拿同一个固定像面上的离焦光斑混作扫描一致性。另有1859组真实球面密集追迹。图表可以切换相干POP能量光斑与统一放大尺度的几何点列；完整通孔NSC模型与源文件一起提供。

同输入相干POP结果：同Z角度/填充位置变化相对零角参考的最大束径偏差约0.437%；跨Z±0.5 mm主域约3.348%，扩展Z±1 mm约6.331%。全部已测姿态的XY平面最大椭圆率约1.0091。主域光束法向面的最大椭圆率约1.0044。上述为采样结果，未将其自动标为材料工艺验收通过。

重建一致性与通孔检查时，在仓库根目录依次运行：

python simulation/deep_hole_v2/build_wall_native.py

`pose_consistency/`保存原生多配置工程、POP分析设置、报告、同尺度图和完整下载包；`wall_inspection/`保存真实通孔、黑壁首次命中与展开回放。ROI和ZRD为本地生成缓存；本目录原始深孔处方及其验证记录保持不变。

## 孔内通道结果

将工件表示为直径0.1 mm、深1 mm的理想直圆柱空孔。光斑中心轨迹直径0.06 mm，检查入口至当前焦面之间的1.5×高斯半径保守包围轮廓，该轮廓对无截断圆高斯束约含98.9%功率。倾斜时采用斜截面的外接圆作保守边界。孔内沿深度另取101个截面。

| 带符号径向AOI | 全深度及方位采样的最小径向余量 |
|---|---:|
| 0° | −13.85 µm，超壁 |
| +1° | +3.59 µm |
| +1.5° | +4.56 µm |
| +2° | +4.56 µm |
| +3° | −6.39 µm，超壁 |
| +5° | −41.68 µm，超壁 |
| −1.5° | −40.07 µm，超壁 |

正向径向倾斜意味着向孔底传播时沿径向向外，从而让上方光束更靠近孔入口中心。这一空孔估算支持优先研究+1.5°～+2°，并不表示所有材料都应使用同一角度。有限采样和1.5倍半径轮廓没有覆盖全部高斯尾部，也不构成连续全域通光证明。

**0.06 mm轨迹不是最终成孔直径。** 有效烧蚀半径需要材料、脉冲能量和脉宽标定。此处空孔已经存在的几何假设，也不能替代从实体材料起钻、逐层去除、排屑和孔壁多次反射的过程模型。

## 相干POP与近轴模型分开记录

POP使用与原工程相同的515 nm、输入束腰半径1 mm、归一化1 W、相干M²=1输入。它没有自动等效实际M²=1.2，不能将其D4σ直接等同上表19.993 µm近轴估计。

| 工况 | POP D4σ主轴直径 / µm | D95 / µm |
|---|---|---:|
| 中心 | 16.665 × 16.665 | 20.439 |
| 入口焦面、AOI+1.5° | 17.148 × 17.158 | 20.984 |
| 孔底X向、AOI+1.5° | 16.172 × 16.184 | 19.725 |
| 孔底Y向、AOI+1.5° | 16.172 × 16.184 | 19.725 |

完整未裁剪网格用于统计，仓库ROI仅供查看。POP仍为开放光路，没有加入圆柱孔壁；超壁以后不能继续用自由传播估计孔底能量。

优化会生成新候选，之后必须重新验证。原生检查新建独立ZOS应用，源文件使用冻结的V1.0快照，不覆盖用户当前工程。原生与POP输入文件SHA256、独立C++/NumPy交叉检查、完整硬件包络分别见本目录JSON记录。实际激光器M²、材料、脉宽和单脉冲能量尚未给出，因此目前只能确认光学候选和理想孔通道的数值结果，不能宣布10:1成孔工艺已验收。
