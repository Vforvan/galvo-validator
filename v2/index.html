主工程说明与参数来源




V2 五轴雅可比方程


执行器输入 u = [G₁, G₂, G₃, G₄, s]ᵀ，工件侧输出 p = [x, y, z, α, β]ᵀ = F(u)。G₁～G₄为振镜机械角（°），s为移动L1的音圈位移（mm）；x、y、z在引擎中使用mm，α、β为出射方向投影角（°）。


F使用当前L1/L2、四振镜、固定折转镜和四片物镜的逐面实光线追迹；焦面由512条等功率高斯采样光线的最小几何RMS确定。α = atan(dx/−dz)，β = atan(dy/−dz)，结果转换为度；不能将振镜机械角直接当成加工入射角。


δp≈J(u0)δu,Jij=∂Fi∂uj


J(u)=[∂x∂G1∂x∂G2∂x∂G3∂x∂G4∂x∂s∂y∂G1∂y∂G2∂y∂G3∂y∂G4∂y∂s∂z∂G1∂z∂G2∂z∂G3∂z∂G4∂z∂s∂α∂G1∂α∂G2∂α∂G3∂α∂G4∂α∂s∂β∂G1∂β∂G2∂β∂G3∂β∂G4∂β∂s]


前三行前四列的单位为mm/°，前三行第五列为mm/mm；后两行前四列为°/°，后两行第五列为°/mm。网页X/Y控件使用µm，因此对应输出增量为1000δx、1000δy。


数值差分与目标五轴逆解

Jij(u)≈Fi(u+hjej)−Fi(u−hjej)2hj


eⱼ为第j个单位向量。当前引擎对振镜使用hⱼ = 10⁻⁵°，对音圈使用h₅ = 10⁻⁵ mm。给定目标p*，每次迭代求解：


J(uk)Δu=p*−F(uk),uk+1=uk+λΔu


求解时将残差与雅可比各行按(1.25 mm，1.25 mm，1 mm，7.5°，7.5°)归一化；缩步λ依次尝试1、1/2、1/4、1/8、1/16，以降低正向计算残差。旋切路径使用完整非线性逆解，各次迭代随当前位姿重新计算J。




当前V2处方在中心的参考系数

参考目标p₀ = (0, 0, 0, 0, 0)，对应u₀ ≈ (0, 0, 0, 0, 0.015198087)。四镜单位为度，音圈单位为mm；下式使用相对此参考位姿的增量：


δx ≈ −1.846759 δG₂ −1.846762 δG₄    [mm]
δy ≈ −2.611710 δG₁ −2.611714 δG₃    [mm]
δz ≈ −0.376412 δs    [mm]
δα ≈ 4.287111 δG₂ +2.282989 δG₄    [°]
δβ ≈ 7.399426 δG₁ +4.565971 δG₃    [°]


系数由当前处方与同一引擎在构建网页时生成；绝对值小于10⁻⁷的数值差分项显示为0。此分组结构只用于中心附近的局部线性化，离轴、倾斜或改变焦点Z后应重新计算完整J。




局部速度关系为ṗ = J(u)u̇。当前网页实现位置路径及逆解，实际轴速度、加速度和同步时间律须另行规划。
