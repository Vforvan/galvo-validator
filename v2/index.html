五轴耦合与同心圆方程
u＝(G1,G2,G3,G4,s)，四个 G 为镜面机械角（°），s 为音圈位移（mm）；p＝(x,y,z,α,β)＝F(u)，F 为当前真实曲面逐面反射/折射及 512 光线最小 RMS 焦面模型。
Dᵢ = 0.1 i mm，i = 1,…,10；θₖ = k°，k = 0,…,360
Aⱼ = j°，j = −5,…,5；z = 启用时的固定 Z
x = (Dᵢ/2) cos θₖ；y = (Dᵢ/2) sin θₖ
α = atan(tan Aⱼ · cos θₖ)；β = atan(tan Aⱼ · sin θₖ)
d = normalize(tan α, tan β, −1)
F(u) − p目标 = 0
J(u) Δu = p目标 − F(u)，u ← u + λ Δu
Jᵢⱼ = ∂Fᵢ/∂uⱼ；局部运动学：ṗ = J(u) u̇
三角函数计算时角度转为弧度；α、β 是投影方向角，不是 AOI 的线性分量。J 为 5×5 耦合雅可比，只有局部可逆时才能反求速度。当前给出位置逆解，尚未加入实际电机速度、加速度、同步及控制器约束。
