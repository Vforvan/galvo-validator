# V2：Ø100 µm × 深1000 µm 圆孔可行性

当前首要目标为直径100 µm、深1000 µm圆孔。30×30 µm、深300 µm、R<4 µm方孔是最终目标，先完成圆孔的光路与孔内送光验证。工作焦距允许调整，当前物镜处方只是候选起点。

网页采用V1式整机三维和五轴控制，保留目标XYZ/αβ、电机直调、光路视角、逐点旋入路径及100 µm孔道检查。当前姿态的孔道包络与三维使用同一组五轴指令。方孔候选、材料去除、能量覆盖、批量光斑矩阵和多候选比较均不在当前入口显示。

## 坐标与使用

- 圆孔入口Z=+0.5 mm、孔底Z=−0.5 mm，孔中心X=Y=0。
- 整机光路中的棕色工件为90×70 mm板面占位，厚度按目标1 mm建模，并包含真实尺寸的Ø100 µm通孔；板面外形不是已选定工件规格。可切换“工件与出光近景”或“100 µm孔剖切”，也可单独隐藏工件。
- 默认旋入路径从入口开始，中心轨迹半径30 µm、径向AOI=+1.5°。正径向AOI表示光向下传播时沿径向向外，从而使入口处的光束更接近孔中心。
- 下方参数生成径向环扫姿态；手动五轴控制还可设置其他方向，孔道检查始终使用实际求解的姿态。
- “检查全深度与整圈”按21个深度（50 µm步距）×24个方位（15°步距）抽查当前半径、AOI及轮廓倍率。更改参数清除旧结论，检查不改变当前三维姿态。
- 1×与1.5×高斯半径轮廓分别包围理想未截断圆高斯约86.5%与98.9%功率。剖面横纵等比例，俯视孔口单独放大；最小余量按三维圆柱孔计算。

## 旋入路径

沿恒定半径圆周向下旋入，每到下一个规划点同时增加深度与方位，不执行定深扫一整圈再换深度。默认每点下钻0.01 mm（10 µm）、转动5°，从0至1000 µm共101个规划点；对应每圈进给0.72 mm，总旋转约1.389圈。下钻量、转角、起止深度、半径和径向AOI可修改。起始方位采用生成路径时的当前方位。

深度以向下为正，网页世界坐标Z向上为正，所以每点下钻0.01 mm对应焦点Z减小0.01 mm。路径为 `X=r cosθ, Y=r sinθ, Z=0.5−depth_mm`；α/β由恒定径向AOI随方位旋转生成，并逐点逆解四振镜与音圈。最后一段若不足一个下钻步长，则同时按比例缩小转角并准确停在终止深度。

“生成旋入路径”回到路径起点；播放与进度条使用同一组规划点，到终点停止。孔剖切中的紫色路径为透视叠加，孔道剖面显示同一轨迹的径向投影。“检查规划点”检查该路径的每个离散点，可取消；调整参数清除旧路径或旧检查结论。导出五轴CSV前自动检查全部规划点，存在失败点时不导出。CSV包含深度、展开方位、XYZ/αβ及五电机指令，未包含控制器插补时间、速度、加速度及脉冲时序。播放遇到遮挡或超限会停在该规划点。

默认路径101个点的检查结果见[旋入路径复核记录](round_helix_verification.json)。它只验证规划点，不把节点间插补、实体材料起钻或实际打穿视为已经通过。

## 验证范围

已有圆孔候选包含423组原目标、3528组深度姿态检查、15组原生配置及4组相干POP检查。本次界面简化复用该处方，没有修改物镜或重新运行Zemax/POP。

新增网页504姿态复核在半径30 µm、AOI=+1.5°、1.5×半径轮廓下未发现电机超限、光学元件采样截光或孔道轮廓触壁；具体数值见[当前网页复核记录](round_web_verification.json)。AOI=0°、−1.5°、+5°的孔底环扫姿态会提示孔壁遮挡风险，不能将倾角越大理解为通光越好。

孔道计算假设理想直圆柱空孔已经存在，使用自由传播近轴高斯保守包络，不模拟起钻、截光后衍射、材料烧蚀及硬件动态。入口接收功率未计后续孔壁遮挡；中心轨迹直径不等于成孔直径。近轴高斯M²=1.2估计与历史相干POP的M²=1结果分别记录。以上是离散光学可行性检查，尚不能宣布材料打穿和成孔质量达标。

## 本地构建

在仓库根目录运行：

```powershell
node analysis/optics_demo/build_round.cjs
node analysis/optics_demo/test_round.cjs
node analysis/optics_demo/test_round_helix.cjs
python simulation/deep_hole_v2/export_round_site.py tmp/galvo-validator-web-v2
```

构建输出为 `output/galvo-validator-v2-deep-unified.html`，可直接离线打开。测试需要Playwright及Edge；可用NODE_PATH指定已安装依赖目录。方孔研究源码和数据仍保留，独立构建命令为 `npm run build:v2-square`。
