# 当前V2：四片物镜重优化主工程

日常只打开 [V2_main.zos](V2_main.zos)。网页、主工程、[design.json](design.json)、[配置表](configurations.csv)及Excel采用同一份已接受的四片物镜参数。试验工程的12组像面配置已融合。旧版V2及独立试验ZOS已从当前目录移除。

本次只同步参数、生成新处方对应的配置指令和合并结构，按用户要求未重跑光学测试。此前六点几何、三点波动的试验记录保留在 关键点光斑试验记录（工程源码的simulation/v2/lens_trial目录），不代表本次合并后的全部160配置重新通过。旧处方工程已退出当前目录；此前已提交内容保留在Git历史。

## 打开与查看

1. 重新打开主工程，比较152与158；原146也保留为同一目标的法向面配置。
2. 标准点列图、POP、Huygens PSF可分别加载同目录的 [V2_spot.CFG](V2_spot.CFG)、[V2_pop.CFG](V2_pop.CFG)、[V2_psf.CFG](V2_psf.CFG)。
3. 切换配置后更新窗口，分析配置使用“当前”。旧分析会话缓存已归档，避免显示旧处方图。

项目XYZ以孔中心和工件中面为基准，Z向上为正；工件中面的全局Z为-80 mm。默认旋入路径半径30 µm、径向AOI1.5°，入口Z=+0.5 mm，每点下行0.01 mm、转5°，到Z=-0.5 mm，共101点。

## 参数与同步记录

四片物镜的8个球面曲率更新，厚度、片间距、首末物理顶点与布局保持。总有效焦距约74.8203 mm；近轴BFL约50.00335 mm，与物理固定末面至中面距离50.00344 mm分别记录。L1/L2及振镜机械结构保持，所有主工程配置指令按新处方重新生成。

- [design.json](design.json)：唯一活动处方。
- [cases.json](cases.json)、[configurations.csv](configurations.csv)：配置目标和指令。
- [configuration_frames.json](configuration_frames.json)：从工程配置参数导出的像面位置和朝向，不是新光学测试。

网页以515 nm、入口1/e²直径2 mm和假设M²=1.2的近轴包络检查理想孔道；目标控件为Ø2.5 mm圆形工作域。已有POP试验为相干M²=1，未覆盖整个工作域；之后的6个NSC代表工况复核见下文。

## 重建

`python simulation/v2/cases.py`生成活动处方对应配置指令。网页构建使用`npm run build:v2 --prefix analysis/optics_demo`，轻量代码检查使用`npm run test:v2 --prefix analysis/optics_demo`，发布使用`python simulation/v2/export_site.py <网页仓库目录>`。内部拓扑种子位于`../deep_hole_v2/_base/geometry_seed.zos`。原生重建、NSC追迹和波动分析须手动运行对应脚本，不会因网页构建而执行。


## 当前角度规划的非序列通光复核

新增一份 [NSC孔道检查工程](nsc/V2_hole_check.zos)，含6个代表配置，采用当前真实光路。径向AOI1.5°～2.5°、半径30 µm的孔底直达比例约99.79%～99.98%；有少量高斯尾部截光。详细口径、探测器38/39/40及结果见 [NSC说明](nsc/README.md)。它不替代全轨迹或材料加工验收。
