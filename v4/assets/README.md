# V4 · 目录镜片固定出口优化

V4 采用三片目录单透镜和四片波长 SCM 目录扫描镜。透镜处方与扫描镜外形采用厂商规格。515 nm 高反膜、装夹后净通光和货期以供应商书面确认为准。

- 详细 V3/V4 镜片与振镜逐项对照、515 nm 焦距/后截距/喷嘴变动原因与官方采购链接见：[V3_V4_LENS_COMPARISON.md](V3_V4_LENS_COMPARISON.md)。

## 1. 光学处方与振镜几何（@ 515 nm）

- **L1（EKSMA 114-1118E）**为双凹 `F_SILICA`，`R1 = -71.84 mm`、`R2 = +71.84 mm`，中心厚 `2.70 mm`，毛坯 `Ø12.70 mm` / 通光 `Ø11.43 mm`。音圈零位的前顶点为 `X = 24.034 mm`，相对上一版沿 X 移动 `-0.966 mm`。
- **L2（OptoSigma SLSQ-25-120P 反置）**为平凸 `SILICA`，平面朝向 L1，`R1 = 0`、`R2 = -55.20 mm`，中心厚 `3.40 mm`，毛坯 `Ø25.00 mm` / 通光 `Ø22.50 mm`。前顶点为 `X = 71.222 mm`，相对上一版沿 X 移动 `+4.000 mm`。
- **F75 物镜（EKSMA 117-5075）**为平凸非球面 `SILICA`，非球面朝向 G4，`R1 = +34.03 mm`、`K = -0.68`、`A4 = 3.50194402615361e-7`、`A6 = 7.05004485494277e-11`、`A8 = 1.1160003658888086e-14`，后面为平面，中心厚 `12.11 mm`，毛坯 `Ø50.80 mm` / 通光 `Ø45.72 mm`。物镜向工件移动 `2.000 mm`，前、后顶点分别为 `Z = -0.769 mm` 和 `Z = -12.879 mm`。
- **G3 等光程优化布局**：保持 `G1=(160, 92, 49.4)`、`G4=(336.08, 192.03, 49.4)` 与三段振镜总光程 `L = 316.106 mm` 不变，将 `G2` 移至 `(160.0, 162.4335, 49.4)`、`G3` 移至 `(245.0, 92.0, 49.4)`：
  - `G3` 入射角由 `~59.9°` 降至 **`46.3°`**（`G1/G3/G4` 名义入射角均回归 `45°–46.3°`，`G2` 为 `24.4°`）。
  - 目录外形（长 × 宽 × 厚，mm）为 G1 `24.4×17.7×2`、G2 `30×21×2`、G3 `45×35×2`、G4 `65×42×2`。Zemax 镜面按目录号标注，矩形光阑依次保留为 `22×16`、`26×18`、`43×33`、`56×38 mm`，作为装夹后需实现的净通光目标。当前光学计算采用理想反射镜。
- **工作平面与喷嘴同步**：工作基准面 `imageZMm = -76.0 mm`（较 V3 `-80.0 mm` 上移 `4.00 mm`），喷嘴直段底面同步由 `-70.0 mm` 缩短至 `-66.0 mm`，保持 `10.0 mm` 喷嘴到工件垂直净空。
- 加工光从机箱前侧进入，在后段沿下方出光，出光轴为 `X = 336.08 mm, Y = 192.03 mm`。固定出口优化最低 Strehl 为 `0.9814`，移动出口候选为 `0.9819`。采用固定出口可沿用现有后罩开口。

## 2. 原生 Zemax 与 1024² POP（21 配置 + 13 工况孔道）

- `V4_main.zos`（仅保存在主机，不提供在线下载） 共 21 个结构。256² FFT 最低 Strehl 为 `0.98143`（结构 19），331 点几何 RMS 半径最大 `2.126 µm`。1024² POP 最大 D95 为 `23.287 µm`（结构 15），上一版为 `20.895 µm`。音圈指令范围为 `-2.4162 .. +2.4975 mm`，机械行程为 `±3.5 mm`。
- `V4_hole_POP.zos`（仅保存在主机，不提供在线下载） 采用同一处方，共 13 个工况。输入 1 W 时，1024² 孔道底面功率为 `0.99345 .. 0.99997 W`，底面 D95 为 `20.385 .. 22.148 µm`。

原生 POP 参考采用半径 1 mm 的 **Gaussian Waist**（等效 **M²=1**），逐工况结果见 [native_POP_reference.json](native_POP_reference.json) 和 [hole_configurations.json](hole_configurations.json)。网页交互包络近似采用 **M²=1.2**。两套光束定义各自对应其光斑结果。

## 3. 五轴逆解与 FPGA Q18 契比雪夫多项式

- 浮点稀疏模型 [model_sparse.json](inverse_validation/model_sparse.json) 和 FPGA Q18 模型 [model_compact_q18.json](inverse_validation/model_compact_q18.json) 均按当前镜座位置重新拟合。
- 离线复核入口为 `python tests/run.py --profile v4-optical-update`，覆盖浏览器、主工程点列及 POP、独立 CCD、离线控制和 Q18 RTL。
- 网页构建、FPGA 实时联调脚本（`fpga_stream.py`）、CK5M 原生插补回放脚本（`trajectory.py` / `sim_pipeline.py`）均已按 `source.release = "v4"` 与 V3 并列隔离支持。

## 4. 独立 CCD 同轴观察工程

`V4_CCD.zos`（仅保存在主机，不提供在线下载） 为非序列装调模型，沿用 V4 的光学处方和 21 组扫描姿态。跨机器使用时，通过 OpticStudio 的「恢复存档」打开 `V4_CCD.ZAR`（仅保存在主机，不提供在线下载），一并载入分光膜和滤光膜数据。

分光片位于 `(336.08, 192.03, 15.0) mm`，采用 1 mm 熔石英平行板和 `34 × 44 mm` 净通光。相对网页初版位置下移 14 mm，为 G3→G4 在极限姿态的入射光束留出空间。515 nm 加工光向下透射，630 nm 工件回光向 −Y 反射，经滤光片和近轴成像镜到达 CCD。膜系、工件回光和相机镜组采用标称模型，实物公差、成像质量及 POP 需单独复核。原生检查入口为 `python tests/run.py --profile v4-ccd-native`。
