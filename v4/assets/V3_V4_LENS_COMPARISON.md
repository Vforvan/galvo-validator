## 2. V3 vs V4 振镜布局与镜片优化对照（G3 等光程优化）

| 振镜轴 | V3 布局与预留尺寸 | V4 优化布局与尺寸 | 优化原因与改善效果 |
|---|---|---|---|
| **G1** | `(160.0, 92.0, 49.4)`<br>`30×25×2 mm`，AOI `49.9°` | `(160.0, 92.0, 49.4)`<br>`SCM-17.7x24.4x2`，**`24.4×17.7×2 mm`**，AOI **`45.0°`** | 净通光要求 `22×16 mm`。短边膜边、倒角与夹持合计只余 `1.7 mm` |
| **G2** | `(170.0, 34.372, 49.4)`<br>`58×40×2 mm`，AOI `19.8°` | **`(160.0, 162.434, 49.4)`**<br>`SCM-21x30x2`，**`30×21×2 mm`**，AOI **`24.4°`** | 净通光要求 `26×18 mm`。按 G2 自身入射角范围配膜 |
| **G3** | `(260.0, 192.03, 49.4)`<br>`64×40×2 mm`，AOI **`59.9°`** | **`(245.0, 92.0, 49.4)`**<br>`SCM-35x45x2`，**`45×35×2 mm`**，AOI **`46.3°`** | 长边从 `64` 缩至 `45 mm`。净通光要求 `43×33 mm` |
| **G4** | `(336.08, 192.03, 49.4)`<br>`58×46×2 mm`，AOI `45.0°` | `(336.08, 192.03, 49.4)`<br>`SCM-42x65x2`，**`65×42×2 mm`**，AOI **`45.0°`** | 净通光要求 `56×38 mm`。短边总共余 `4 mm`，需确认夹持和转动惯量 |
| **振镜总光程 `L`** | `58.49 + 181.54 + 76.08 = 316.106 mm` | `70.43 + 110.39 + 135.28 =` **`316.106 mm`** | 目录外形替换沿用 V4 镜心、反射面、转轴与设计矩形光阑 |

本版沿用四片振镜的镜心和出光轴。L1、L2 的前顶点分别移到 `X = 24.034 mm` 和 `X = 71.222 mm`，F75 向工件移动 `2.000 mm`。原生结果采用设计净通光和理想反射面。 [主工程 21 结构 Strehl 与 POP](native_POP_reference.json)、[孔道 13 工况 POP](hole_configurations.json)

## 3. 工作面与喷嘴变动说明

| 系统 / 机械参数 | V3 | V4 | 变动与原因说明 |
|---|---:|---:|---|
| `F75 后顶点` → `名义工作面 Z0` 距离 (mm) | `68.037`（`Z0 = -80.0`） | `63.121`（`Z0 = -76.0`） | V4 后顶点为 `Z = -12.879 mm`，几何工作距为 `\|-12.879 - (-76.000)\| = 63.121 mm` |
| 名义工作平面 `imageZMm` (mm) | **`-80.00`** | **`-76.00`** | **相对 V3 沿 +Z 向物镜上移 `4.00 mm`** |
| 喷嘴直段位置 `topZ / bottomZ` (mm) | `-55.0 / -70.0` | **`-55.0 / -66.0`** | 喷嘴直段缩短 `4.00 mm`（`15 -> 11 mm`），底面升至 `-66.0 mm` |
| 喷嘴底面到工作面垂直净空 (mm) | `10.0` | **`10.0`** | 在新焦点上移 4 mm 后，保持原本 `10.0 mm` 工艺/气流安全净距 |
| `cfg-1 (0,0,0,0,0)` 音圈指令 `vc` (mm) | `-0.9493`（工作基准面 `-80`） | **`0.0000`**（工作基准面 `-76`） | V4 中心工况对应音圈零位 |
| 21 配置音圈指令范围 (mm) | `[-3.3009, +1.7204]` | **`[-2.4162, +2.4975]`** | 音圈机械行程为 `±3.5 mm` |
| 21 配置最低 Strehl / 最大 D95 | — | **`0.98143 / 23.287 µm`** | Strehl 采用 256² FFT，D95 采用 1024² POP。13 工况孔底功率为 `0.99345 .. 0.99997 W`（输入 1 W） |
